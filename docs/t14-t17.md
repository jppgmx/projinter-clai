# T14–T17 — ajustes de formulários

- T14: turma passa a ser select no cadastro e edição, com as quatro opções fornecidas: Banco de Dados II, Gerência de Projetos de Software, Laboratório de Engenharia de Software, Laboratório de Redes de Computadores. Na edição, turmas antigas fora da lista são preservadas.
- T15: nascimento usa input date; atendimentos/anamnese usam uma ou mais datas, e documentos separam data de profissional/observações. Valores antigos são preservados sem alteração quando não editados. Datas antigas dd/MM/yyyy são carregadas nos seletores; conteúdos adicionais permanecem disponíveis. Períodos letivos continuam sendo períodos, como 2026.1.
- T16: parentesco passa a select no cadastro e edição, incluindo Mãe, Pai e Responsável legal. Valores antigos fora da lista são preservados na edição.
- T17: abertura pesquisa nome ou matrícula a partir de 3 caracteres, aguarda 250 ms, utiliza GET /api/estudantes?busca= e mostra até 5 sugestões. Requisições obsoletas são canceladas; editar a busca invalida a seleção. Suporta teclado e pré-seleção pela matrícula da URL.
- Nenhum contrato Java, tabela ou credencial foi alterado. A busca usa a API existente; a limitação de cinco resultados é aplicada na interface.
- Fontes dos formulários: apps/frontend/html e apps/frontend/js. A interface compilada precisa ser atualizada também em apps/backend/src/main/resources/static para execução direta pelo Spring.
